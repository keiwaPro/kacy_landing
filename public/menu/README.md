# Photos du menu (mini-app)

Déposer ici les deux photos affichées dans la carte « mini-app » du bento :

| Fichier | Plat | Format conseillé |
| --- | --- | --- |
| `poulet-braise.jpg` | Poulet braisé | carré ou 4:3, ~600 px de large |
| `garba.jpg` | Garba spécial | carré ou 4:3, ~600 px de large |

Tant que les fichiers sont absents, un dégradé de repli s'affiche à leur
place (voir `.mapp-media` dans `src/app/v2.css`) : aucune image cassée.
